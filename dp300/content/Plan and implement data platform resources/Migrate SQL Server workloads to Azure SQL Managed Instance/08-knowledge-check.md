## Check your knowledge

1. In a transactional replication topology, which roles can Azure SQL Managed Instance perform?

- Publisher, distributor, and subscriber.
- Subscriber only.
- Distributor only.

2. What is the primary use case for the Log Replay Service for Azure SQL Managed Instance?

- To migrate databases from on-premises SQL Servers or virtual machines to Azure SQL Managed Instance with minimal downtime
- To migrate data from other cloud providers to Azure SQL Managed Instance
- To migrate data from Azure SQL Database to Azure SQL Managed Instance

3. What is the purpose of using SQL Managed Instance link feature during migration?

- To create an availability group listener on the source and target.
- To minimize downtime during migration by extending an on-premises database into the cloud.
- To create a Windows Server Failover Cluster on the source and target.
