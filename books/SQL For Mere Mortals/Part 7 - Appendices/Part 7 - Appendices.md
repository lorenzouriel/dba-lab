# Part 7: Appendices

Not a narrative part — reference material to dip back into while reading (or re-reading) Parts 1-6, not something to read start to finish.

1. **Appendix A — SQL Standard Diagrams.** The railroad-diagram notation the book leans on for SELECT/JOIN/CASE/window-function grammar. Useful the first time a diagram-shaped explanation shows up anywhere else in the book.
2. **Appendix B — Schema for the Sample Databases.** "Which database has which tables" — Sales Orders, Entertainment Agency, School Scheduling, Bowling League, Recipes, plus the Chapter 20 driver tables. Come back here whenever an example references a table by name and the context isn't obvious.
3. **Appendix C — Date and Time Types, Operations, and Functions.** Cross-platform cheat sheet (DB2, Access, SQL Server, MySQL, Oracle, PostgreSQL) for date/time types, arithmetic, and function names — the least portable corner of SQL, so this is the one appendix worth bookmarking rather than reading once.
4. **Appendix D — Suggested Reading.** Where to go next: database design theory, SQL Standard reference, advanced SQL technique.

Treat this part as an index, not a chapter sequence.
